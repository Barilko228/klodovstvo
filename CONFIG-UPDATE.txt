ЧТО ДОБАВИТЬ В config.php НА ХОСТИНГЕ
=====================================

Файл config.php не трогай целиком — там твои доступы к банку.
Открой его в менеджере файлов и найди строку со ссылкой на курс:

    'course_link'  => 'https://t.me/+G2O9nigl3MZiMGZi',

Замени её на такой блок (свой канал под каждый тариф):

  // ── закрытые каналы с курсом: свой на каждый тариф
  'course_links' => [
    '1' => 'https://t.me/+Z13BuLV0GxA4NGFi',   // Ученик, 4 990
    '2' => 'https://t.me/+CqTPDvAG5uNmYjYy',   // Клодун, 9 990
  ],

Сохрани. Больше в этом файле ничего менять не нужно.
